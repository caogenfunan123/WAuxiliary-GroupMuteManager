# WAuxiliary 群免打扰管家

微信 **8.0.74** + WAuxiliary **1.2.7.r1481.8fec76f** 实测通过的群聊消息免打扰批量管理插件。

> ⚠️ **兼容性声明：仅在微信 8.0.74（FKZ / xspace-virtualized build，加密 EnMicroMsg.db）上测试成功。**
> 其他微信版本类名/字段/偏移大概率变化，直接照搬不保证可用，请按 `docs/` 里的方法重新核对反编译证据。

## 功能

| 入口 | 行为 |
|---|---|
| 主页加号菜单「群免打扰管家」 | 打开管理面板：搜索/关键词过滤全部群聊，点选逐个或批量开关消息免打扰 |
| 任意聊天界面发送 `群聊免打扰` | 拦截该消息（不会真发出去），直接打开本插件管理面板 |
| 会话列表长按 → 免打扰开关 | 对单个群聊快速切换 |

写入链路与微信原生 `RoomInfoDetailUI`（群聊信息页）**完全同源**：原生 setter + T 缓存字段 + oplog **cmd20 notify 任务** + attrflag + SharedPreferences 六路齐发，静音状态经服务端同步，不回弹。

## 安装

1. 微信 + [WAuxiliary](https://github.com/ujhhgtg/wauxiliary-base) 模块（需 root / LSPatch，版本 ≥ 1.2.7）
2. 把 `plugin/` 整个目录复制到：
   ```
   /storage/emulated/0/Android/media/com.tencent.mm/WAuxiliary/Plugin/群免打扰管家
   ```
3. 重启微信（模块只在微信进程启动时读取插件目录）
4. 主页加号菜单 / 任意聊天发送 `群聊免打扰` 呼出面板

## 用法

- **批量**：面板输入关键词过滤群聊 → 勾选 → 底部「开启免打扰 / 关闭免打扰」
- **单个**：会话列表长按群 → 「免打扰开关」
- **状态互认**：插件设置的静音，群聊信息页顶部开关、会话列表静音图标、通知抑制全部同步生效；反之在系统页面里操作，插件读取的也是同一状态

## 状态判定（重要）

微信里"免打扰"有**三个不同层面**，历史上所有失败都源于混淆它们：

| 层面 | 载体 | 说明 |
|---|---|---|
| 真·静音 | 联系人 `type` bit 512（`c01.e2.P(z3)`） | 通知/列表图标的最终依据，服务端同步的也是它 |
| 页面开关显示 | 联系人 `z3.T`（缓存字段，**非 DB 列**）+ SP `room_msg_notify` | `T=0` → 开（mute ON），`T=1` → 关；重启后靠缓存回填 |
| 服务端状态 | oplog **cmd20** notify 任务（`mn.a(username, g, 0)`） | `g=0` → 开，`g=1` → 关；不发这个，服务端同步回来就把本地冲掉 |
| 红点/角标 | `rconversation.attrflag` bit `0x200000` | `m4.Z(roomId, 0x200000, mute, cur)` |
