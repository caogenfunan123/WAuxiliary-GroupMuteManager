## 本项目踩过的环境坑（复现用）

1. **多包一层 `Object[]`**：`byte[]` 作为 `new Object[]{...}` 元素进反射 invoke/newInstance → ART 炸、JVM 过。绕过法：latin1 String + `protobuf.g.a(str,"ISO-8859-1")`
2. **WAux bsh lambda 闭包**：同一 lambda 调用链里别重名局部变量（闭包串写），统一 `s/m/o` 前缀
3. **反射 ctor 按 smali 声明类型找**（`xg3.p0(int, protobuf.f)` 是基类，不是具体 `r45.tn4`）
4. **插件元数据只在微信启动时读**，改 `info.prop`/`readme.md` 必须重启微信
5. **描述显示**靠插件目录 `readme.md`，不是 `info.prop` 的 `desc=`
