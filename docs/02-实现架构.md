# 02 · 实现架构（最终版 v2.10.x）

全部写入逻辑集中在 `plugin/mute_core.java`，反射定位全部走 DexKit 锚点字符串 + 备选 loader，**不写死偏移**。

## 核心函数

| 函数 | 作用 |
|---|---|
| `_gmInit()` | DexKit 锚定 `c01.e2.p0/z0`（DND add/cancel 字符串），加载 `gm0.j1`/`vg3.x3`/`k4`(Bi)/任务队列(`fj`)/存储(`Di`) |
| `_gmSetMute(roomId, mute)` | 五路写入（见下） |
| `_gmIsMuted(roomId)` | `((Integer)Bi().n(roomId,true).getType() & 512) != 0` |
| `_gmSendOplogMute(roomId, mute)` | **关键**：构造 `mn.a(roomId, g, 0)` 压 `fj().c()` |
| `_gmContact(roomId)` | `Bi().n(roomId, true)` 取缓存 bean |

## 五路写入链（`_gmSetMute`）

```
① 原生 setter：c01.e2.p0(stub, true) 静音 / c01.e2.z0 取消
   stub = new c01.e2(roomId)              → type512 立即生效
② 本地持久化：obj = Bi().n(roomId, true)
   obj.setType(mute ? t|512 : t&~512)
   obj.J2(mute ? 0 : 1)                    ← 极性：静音=0（与原生页面一致）
   Bi().p0(roomId, obj)                    ← 缓存+DB
③ attrflag：m4.Z(roomId, 0x200000, mute, cur)
④ 服务端：new mn.a(roomId, mute?0:1, 0) → fj().c(task)   ← cmd20，不回弹的关键
⑤ SharedPreferences：pkg + "_preferences" 的 room_msg_notify = mute
   Context 取 com.tencent.mm.sdk.platformtools.x2 的静态 Application 字段
```

## 为什么 cmd20 是"回弹"的分水岭

- `c01.e2.g0(z3, bool)`（原生 setter 内部）只会推 `new xg3.p0(2, e2.n(z3))` —— **modContact，cmd 2**，字段里带 mute（`r45.tn4.w = z3.T`），但服务端对"通知开关"的认账通道显然不是它；
- `RoomInfoDetailUI` 的点击 handler 推的是 `new mn.a(this.p, this.g, 0)` —— **`xg3.q0` 子类，super q0(0x14) → cmd 20**，载荷 `r45.rn4{du5 username, int e=g, int f=0}`；
- 两条都是 `fj().c(task)` 的任务，且 UI 路径没有 callback、不碰 type512——type512 是服务端处理完 cmd20 后**随同步回来**写上的。

实测证据：只发 cmd2（队列/RunCgi 两种姿势都试过）→ 最多 2 分钟被冲掉；补上 cmd20 → 连续切换多个群保持不回弹。

## 前台功能

- `onCreateHomePopMenu`：主页加号加「群免打扰管家」入口
- `onCreateConversationItemMenu(conversationBean)`：会话长按菜单「免打扰开关」，`getUsername()` 反射取 roomId
- `onClickSendBtn(text)`：`text.trim()=="群聊免打扰"` → 拦截（return true，不真发）→ `openSettings()` 打开面板
- `_gmShowSearchDialog()`：搜索面板（`mute_ui.java`），内存过滤 `备注+昵称+群名`，点选批量写

## WAux 接入要点

- 描述**不是** `info.prop` 的 `desc=`，是插件目录 `readme.md`（demo 同款）
- 插件元数据只在**微信进程启动时**读取——改完 `info.prop`/`readme.md` 必须 `am force-stop com.tencent.mm` 再拉起
- `mute_ui.java` 的 lambda / Runnable 内**不要重名局部变量**（WAux bsh lambda 闭包 bug），全部 `sXxx/mXxx/oXxx` 前缀
